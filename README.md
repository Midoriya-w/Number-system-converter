# Number System Converter
Open `index.html` in a browser, or open the folder in VS Code and run it with Live Server. No Node.js, backend or database is required.

Features: binary/octal/decimal/hex conversion, validation, copy buttons, recent history, conversion explanation, complements, binary addition/subtraction and 8-bit visualizer.

The browser interface does not execute the 8086 assembly. Place the verified `.asm` source in `assembly/` and assemble/run it separately in EMU8086.
